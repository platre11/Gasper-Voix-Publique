# Gasper Voix

Application Android pour GrapheneOS (Pixel 9a et 10a) : tu enregistres un message vocal, ta voix est modifiée directement sur le téléphone, puis tu l'envoies dans la messagerie de ton choix.

- Aucun accès Internet : l'application n'a pas la permission réseau.
- Ta voix d'origine n'est jamais enregistrée sur le téléphone.
- Les messages sont supprimés automatiquement.

L'application est réservée aux téléphones Gasper et demande un code d'activation.

## Installer

1. Ouvre l'onglet **Releases** de ce dépôt (à droite sur la page).
2. Télécharge le fichier `gasper-voix-X.Y.Z.apk` de la dernière version.
3. Ouvre le fichier. Si le téléphone le demande, autorise ton navigateur à installer des applications, puis installe.
4. Une fois l'installation terminée, retire cette autorisation au navigateur.

Android 15 ou plus est nécessaire.

## Mises à jour

Pour recevoir les mises à jour sans rien refaire à la main, installe l'application **Obtainium**, puis ajoute ce dépôt dans Obtainium (`https://github.com/platre11/Gasper-Voix-Publique`). Les nouvelles versions s'installent par-dessus l'ancienne, sans perdre tes réglages.

Sans Obtainium, il suffit de télécharger la nouvelle version et de l'ouvrir : elle remplace l'ancienne.
